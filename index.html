01 — About

Engineer first,
builder always.

I'm Pratham, a final-year Computer Science student at the University of Calcutta. I got into engineering the usual way — curiosity about how things work — and stayed because I like the part where something finally runs.

My work sits where hardware meets interface. I've built an IoT cardiac monitor that dispatches emergency alerts over a blockchain ledger, and an OCR pipeline that reads Hindi and English out of the same image. Both started as hackathon problems with a clock running.

I care about the unglamorous parts: latency, failure states, and whether the thing still works when the network drops. That's usually where a project earns its keep.

03 — Lab

The same face,
rendered.

A real-time 3D avatar built in Three.js. Drag to orbit, scroll to zoom. It's the same person as the sequence above — one is a film, this one is geometry.

Your browser can't render WebGL, so here's the short version: it's a 3D model of me.

Drag to orbit

Built with Three.js

The model is compressed with Meshopt and its textures re-encoded to WebP, which takes it from 9.6 MB down to about 1 MB. Lighting is a three-point studio rig — key, fill and rim — so the silhouette reads against the dark ground.

RendererThree.js · WebGL2
CompressionMeshopt + WebP
Payload1.0 MB
InteractionOrbit · Damped
